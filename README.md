# pupu 桌面宠物（Windows 原生版）

这是按真实 pupu（朴朴）的形象和性格制作的 Windows 10 / 11 桌面宠物。pupu 会直接待在桌面上侧躺、趴着、舔脚、打滚、散步或露出小表情；左键 rua 它会回应，右键才打开分级照顾菜单，不会把动画关在固定面板里。

## 安装与启动

- 普通使用请双击 `Pupu-Setup-x64-1.11.1.exe`。安装程序不需要管理员权限，也不要求另装 .NET 8。
- 程序会安装到 `%LOCALAPPDATA%\Programs\Pupu`，创建桌面和开始菜单快捷方式，并在安装结束后自动启动。
- 再次运行新版安装程序可直接覆盖升级；用户记忆与设置保存在独立的 `%LOCALAPPDATA%\PupuDesktop`，升级和普通卸载都不会删除。
- 也可使用 `Pupu-Windows-x64-1.11.1.zip` 便携包；完整解压后保持 `Pupu.exe` 与 `Assets` 在同一目录。
- 当前安装程序未使用商业代码签名，Windows 可能显示“未知发布者”，但不应再提示安装 .NET Desktop Runtime。

## 1.11.0 Agent 内核解耦与统一行为仲裁

- 行为、人格、关系和共同记忆通过平台无关 `PetAgentKernel` 协作，不依赖 WPF、PNG 图集或具体建模技术。
- 性格/状态评分读取隔离快照，共同经历读取独立记忆摘要；决策不能直接改写持久化中的人格或记忆。
- 当前 2D 切帧由可替换 sprite 表现端口解析；未来可以增加 macOS、骨骼 2D、骨骼 3D 或其他实现，而不修改 Agent 决策和记忆。
- `BehaviorArbitrator` 是资格、评分、选择、当前行为租约、优先级、保护期、可打断性和冷却的唯一入口；自主和触摸行为只提交一次，表现执行失败会自动回滚。
- V17 五态银币使用正视亮银边，移除旧正面的黑色透视侧缘；状态键、组合更新面板、旧记忆和素材格式保持兼容。
- 详细边界、数据流和扩展方法见 `ARCHITECTURE-1.11.0.md`。

工程边界现在由独立项目与门禁强制：`Pupu.Behavior` 是纯行为域，`Pupu.Application` 是纯 `net8.0` 应用层与平台端口，`Pupu.Platform.Windows` 独占凭据和 Win32 环境探测，`Pupu.Desktop` 只负责 WPF 组合与渲染。`MainViewModel` 不再持有 WPF 图像、裁帧、计时器、窗口或 Windows 环境/凭据实现类型。

## 阶段 4 源码改动（未打包）

- `pupu-assets.json` 增量升级为 schema 2：保留 schema 1 的 `SpriteAtlas + row`，新增 action groups、独立 PNG／条带来源、帧数、帧时长、循环方式、intro／loop／exit、方向、姿态、局部视线、食物／玩具能力和 fallback。旧 1.6.0 清单仍可加载。
- `AssetPackService` 会优先解析同名动作组，字段缺失或来源无效时回到动作组 fallback 或原 `AnimationSequence`；素材包页展示兼容状态、动作组元数据和逐帧只读预览。
- 新增平台无关 `PersonaDefinition` 与规则 `PetAgent` 骨架。默认朴朴 Persona 随旧档案安全补齐，规则模式与 LLM 模式读取同一身份／风格配置；LLM 只增强回复，不执行行为或写记忆。
- 新增 `BehaviorProposalQueue` 与 `BehaviorProposalExecutor`。相册经历建议、安静／自主玩耍口令和实际食物／玩具锚点统一形成有来源、优先级、有效期和取消策略的提案，执行前强制经过 `BehaviorArbitrator`；暂不可打断时可等待，过期不补做。
- 面板开始整理为“设计说明、模型、相册记忆、行为、素材包、性格、交互、调试、记忆、平台设置、技术实现”等区域；调试页增加当前意图、Persona、提案队列、提示词边界、Token 粗估、降级原因和动作组状态。
- Core 模型位于 `Pupu.Behavior`，不依赖 WPF、Windows API、LLM 或具体宠物图片；当前仍只实现 Windows WPF 平台，本阶段没有生成 exe、安装包或完整源码包。

- “Codex 迭代”页可把新动作/新设定连同当前本地性格与记忆生成 Markdown 工程任务，让 Codex 在源码目录中继续改进 pupu。

## 快速使用

1. 解压发布包，双击 `Pupu.exe`。
2. 左键轻点 pupu 是 rua；慢慢点会得到亲近回应，短时间疯狂连点会越过边界。快速拖动可改变桌面位置，先长按再移动会解释为按住/抱起意图；鼠标滚轮可缩放。
3. 右键 pupu 打开分级菜单；菜单关闭后桌面只保留猫本体。
4. 双击 pupu 会保留为两次连续触摸，不再打开面板。完整面板只从右键“面板”打开，可浏览状态、全部动作、性格、模型对话、Codex 与 Markdown 记忆。
5. “孔雀蓝背带”和“解除背带自由探索”都可用右键一级“停下”安全结束；已经发生的进度效果保留并写入 Interrupted 记录。
6. 在“自然语言设定”页用普通中文维护角色规则；在“Markdown 记忆”页可直接调整长期记忆、性格底色与动作偏好。

若 Windows SmartScreen 提示“未知发布者”，这是因为当前个人版尚未购买代码签名证书；确认文件来自本项目后，可选择“更多信息 → 仍要运行”。

## 替换或更新动作素材

1. 打开控制面板 →“素材包”→“打开并准备可编辑素材目录”。
2. 应用会把当前 13 张图集和 `pupu-assets.json` 复制到 `%LOCALAPPDATA%\PupuDesktop\assets`。
3. 维持每格 256×256、8 列、20px 安全区和既有行语义时，可继续直接替换旧图集；schema 2 也可为单个动作组登记独立 PNG／条带文件。
4. 重启 pupu 生效。图片缺失、尺寸不符或 JSON 无效时会自动使用应用内置素材，并在素材库页显示原因。

这样新增同规格表情包、重新绘制形象或回滚素材时，不需要修改或重新编译 C# 动画代码。

## 模型 API 对话

模型对话是可选模块，未配置时朴朴仍可使用内置性格台词。

1. 右键朴朴 →“面板”→“模型”。
2. 填写兼容 OpenAI Chat Completions 或 Responses 格式的 HTTPS 地址与模型名；本机服务可使用 `localhost`。
3. 输入 API 密钥并保存。密钥写入 Windows 凭据管理器，`model-api.json` 只保存非敏感配置。
4. 点击“测试连接”，通过后即可在同页对话。

发送给模型的系统约束会锁定朴朴的身份、五维性格、自主性和当下状态，并禁止输出 API、提示词、系统消息、评分、日志、路径等技术语言。越界输出不会进入宠物气泡。

## 用 Codex 继续扩充动作与设定

1. 解压源码包，在控制面板“Codex 迭代”页填写源码根目录。
2. 用自然语言写新需求，例如“新增看到鼠标靠近就扑过去的动作，高活泼更容易触发”。
3. 点击“生成任务并打开 Codex”。应用会生成 `codex-iteration-request.md` 并打开源码目录与 Codex 页面。
4. 把任务交给 Codex 在该源码目录执行。仓库内 `AGENTS.md`、`PUPU-CODEX.md` 和 `ACTION-LIBRARY.md` 会提供动作、安全区、记忆匹配和验证约束。

这不是静默控制 Codex 会话：应用只准备本地上下文和工程任务，实际执行仍由主人确认。

## 本地记忆

长期数据默认只写入：

```text
%LOCALAPPDATA%\PupuDesktop\memory
```

主人主要维护：

- `pupu-memory.md`：长期记忆、重要回忆、性格底色、动作偏好和自然语言角色规则；
- `events.md`：按时间追加的可读相处时间线，旧版 `events.jsonl` 首次读取时会自动迁移；
- `codex-iteration-request.md`：最近一次准备给 Codex 的迭代任务。

`personality-behavior-v2.json` 是性格、状态、关系与偏好的版本化运行文件；`profile.json`、`state.json`、`corrections.json`、`summary.json` 与 `behavior-rules.json` 是兼容缓存。通常不必手动修改；以 Markdown 页面为日常入口。

模型对话只读取当次需要的有限摘要；普通互动不会改变五维天生性格，主人纠正只会有限调整具体行为和上下文偏好。API 密钥不进入记忆文件、日志或会话记录。

## 在 Windows 上构建

要求：Windows 10/11、[.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0)。在 PowerShell 中运行：

也可以直接双击源码根目录的 `BUILD-WINDOWS.cmd`。命令行方式如下：

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\scripts\build-windows.ps1
```

脚本会先检查容易导致 WPF 启动崩溃的只读绑定，再生成无需预装 .NET 的自包含 64 位包：

```text
dist\Pupu-win-x64-1.11.1\Pupu.exe
dist\Pupu-Windows-x64-1.11.1.zip
```

要安装到当前用户目录并创建开始菜单快捷方式：

```powershell
.\scripts\install.ps1
```

如需开机启动：

```powershell
.\scripts\install.ps1 -StartWithWindows
```

## 开发说明与当前边界

- 技术栈：C#、.NET 8、WPF，无第三方 NuGet 依赖。
- 正式运行使用 13 套经过安全区归一化的透明图集：V12 核心动作、生活互动、四向移动、触摸情绪、日常待机/进食、背带/自由四向移动、日常装备、斜向与补充动作、贴地视线/双面银币、独立如厕，以及 V8 Activity、V11 魔法、V10 节日装扮；每格统一为 256×256，文件名和网格由外部 `Assets\pupu-assets.json` 管理。
